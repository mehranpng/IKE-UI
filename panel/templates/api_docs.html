RESTful Integration API

IKE-UI API Reference

Seamlessly connect external management portals, automation bots, billing systems, or AI agents to your IKEv2 / IPsec StrongSwan VPN server.

API Base URL

{{ api_base_url }}

Authentication

Every request to the API requires an active API key generated from Settings > API Access & Integrations. Send the API key with every request using either header:

HTTP Header Option 1: X-API-Key 
X-API-Key: sk-your-api-key
HTTP Header Option 2: Authorization Bearer 
Authorization: Bearer sk-your-api-key
Security Note: API keys start with sk-. The full key is displayed only once upon generation. Keep it secure; if lost, regenerate a new key from Settings.
GET /stats
Dashboard & Hardware Metrics

Retrieves live server performance metrics (CPU, RAM, Disk, Net Rx/Tx) and aggregate VPN statistics (total, active, and online users, plus total traffic consumed).

curl -s '{{ api_base_url }}/stats' \

GET /users
List & Search Users

Returns a paginated list of VPN users with filtering by query keyword.

Query Parameter Type Required Description
q string Optional Search keyword filtered against username or notes.
page integer Optional Page number (default: 1).
per_page integer Optional Number of items per page (default: 25, max: 100).
cURL Request 
curl -s '{{ api_base_url }}/users?q=alice&page=1&per_page=25' \
  -H 'X-API-Key: sk-your-key'
Response 200 OK 
{
  "success": true,
  "users": [
    {
      "id": 1,
      "username": "alice",
      "is_active": true,
      "max_traffic_gb": 50,
      "used_traffic_bytes": 104857600,
      "expire_date": "2026-12-31 23:59:59",
      "max_devices": 3,
      "note": "VIP Client",
      "portal_url": "{{ portal_base_url }}/sub?u=alice"
    }
  ],
  "pagination": {
    "page": 1,
    "per_page": 25,
    "total_items": 1,
    "total_pages": 1
  }
}
POST /users
Create New User

Creates a new VPN user account. The plaintext password and direct user portal link are returned in the response.

JSON Body Field Type Required Description
username string Required Alphanumeric username (3–32 characters). Must be unique.
password string Optional User password. If omitted, a secure 8-character random password is auto-generated.
duration_days integer Optional Validity in days from now. Use 0 for lifetime / unlimited. Default: 30.
max_traffic_gb number Optional Traffic limit in Gigabytes. Use 0 for unlimited traffic. Default: 0.
max_devices integer Optional Simultaneous connected devices limit (1 to 10). Default: 10.
note string Optional Optional customer memo, reference ID, or telegram username.
cURL Request 
curl -s -X POST '{{ api_base_url }}/users' \
  -H 'X-API-Key: sk-your-key' \
  -H 'Content-Type: application/json' \
  -d '{
    "username": "bob",
    "password": "SecurePassword123",
    "duration_days": 30,
    "max_traffic_gb": 100,
    "max_devices": 3,
    "note": "Office User"
  }'
Response 201 Created 
{
  "success": true,
  "user": {
    "id": 2,
    "username": "bob",
    "password": "SecurePassword123",
    "is_active": true,
    "max_traffic_gb": 100,
    "used_traffic_bytes": 0,
    "expire_date": "2026-10-17 22:30:00",
    "max_devices": 3,
    "note": "Office User",
    "portal_url": "{{ portal_base_url }}/sub?u=bob"
  }
}

PATCH /users/{id}
Update User Account

Updates traffic allowance, expiration, device limit, note, password, or active state. Supports both PATCH and PUT.

JSON Body Field Type Description
duration_days integer Reset expiration date to X days from today. Pass 0 to set as lifetime.
max_traffic_gb number Updated traffic quota in GB. Pass 0 for unlimited.
max_devices integer Maximum concurrent devices (1 to 10).
note string Updated memo note.
is_active boolean Enable (true) or disable (false) the user account.
password string New connection password.
cURL Request 
curl -s -X PATCH '{{ api_base_url }}/users/2' \
  -H 'X-API-Key: sk-your-key' \
  -H 'Content-Type: application/json' \
  -d '{
    "max_traffic_gb": 200,
    "duration_days": 60,
    "note": "Subscription Renewed"
  }'
POST /users/{id}/password
Change Password

Updates the user's connection password and automatically synchronizes IPsec StrongSwan secrets in real time.

cURL Request 
curl -s -X POST '{{ api_base_url }}/users/2/password' \
  -H 'X-API-Key: sk-your-key' \
  -H 'Content-Type: application/json' \
  -d '{"password": "BrandNewPassword456"}'
POST /users/{id}/status
Enable / Disable User

Toggles user active status. Setting is_active: false immediately terminates all active VPN tunnel sessions for that user.

cURL Request 
curl -s -X POST '{{ api_base_url }}/users/2/status' \
  -H 'X-API-Key: sk-your-key' \
  -H 'Content-Type: application/json' \
  -d '{"is_active": false}'
DELETE /users/{id}
Delete User

Permanently deletes the user account, removes credentials from IPsec secrets, and disconnects all active connections.

cURL Request 
curl -s -X DELETE '{{ api_base_url }}/users/2' \
  -H 'X-API-Key: sk-your-key'
GET /backup/users
Export Users Database

Downloads a standalone SQLite database backup (.db) containing all user accounts, encrypted credentials, quotas, and metadata. Compatible with the restore feature.

cURL Download 
curl -s -OJ '{{ api_base_url }}/backup/users' \
  -H 'X-API-Key: sk-your-key'
POST /restore/users
Restore Users from Database

Restores VPN user accounts from an SQLite database backup file (.db, .sqlite, or .sqlite3). The endpoint verifies file signature, integrity, schema compatibility, atomically replaces the accounts, re-syncs StrongSwan secrets, and terminates obsolete sessions.

Form Multipart Field Type Required Description
backup_file file binary Required SQLite database file (.db, .sqlite, .sqlite3). You can also send field name as file. Max size: 50MB.
cURL Request (Multipart Upload) 
curl -s -X POST '{{ api_base_url }}/restore/users' \
  -H 'X-API-Key: sk-your-key' \
  -F 'backup_file=@ike_users_backup_20260917.db'
Response 200 OK 
{
  "success": true,
  "message": "Successfully restored 15 users!",
  "restored_count": 15
}

Responses & Error Handling

All API endpoints return consistent JSON payloads. Successful operations include "success": true, while errors include "success": false with a descriptive "error" message string.

HTTP Status Status Name Meaning
200 OK The request succeeded.
201 Created The resource was successfully created.
400 Bad Request Malformed JSON, missing required fields, or invalid file format.
401 Unauthorized Missing or invalid API key.
404 Not Found The requested user ID or endpoint does not exist.
409 Conflict Duplicate resource (e.g. username already taken).
500 Server Error An unexpected internal server error occurred.
Standard Error Response Example 
{
  "success": false,
  "error": "Invalid file format. Only .db, .sqlite, and .sqlite3 files are allowed."
}
