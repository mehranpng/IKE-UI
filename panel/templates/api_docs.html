API v1

IKE-UI API

Connect your tools and automations to the panel through a simple API.

Base URL

{{ api_base_url }}

Authentication

Send the API key with every request using either X-API-Key or Authorization: Bearer <key>. Keys start with sk-.

curl '{{ api_base_url }}/users' \
  -H 'X-API-Key: sk-your-key'

Endpoints

MethodPathPurpose
GET/usersList users. Supports q, page, per_page.
POST/usersCreate a user.
GET/users/{id}Get one user.
PATCH / PUT/users/{id}Edit traffic, expiry, note, devices and active state.
POST/users/{id}/passwordChange the password.
POST/users/{id}/statusEnable or disable a user.
DELETE/users/{id}Delete a user and disconnect active sessions.

Search by username with the q parameter:

curl '{{ api_base_url }}/users?q=mehran' \
  -H 'X-API-Key: sk-your-key'

Create

curl -X POST '{{ api_base_url }}/users' \
  -H 'X-API-Key: sk-your-key' -H 'Content-Type: application/json' \
  -d '{"username":"alice","password":"strong-password","duration_days":30,"max_traffic_gb":100,"max_devices":3,"note":"Team A"}'

Example response:

{
  "success": true,
  "user": {
    "id": 12,
    "username": "alice",
    "password": "strong-password",
    "is_active": true,
    "max_traffic_gb": 100,
    "used_traffic_bytes": 0,
    "expire_date": "2026-10-14 12:30:00",
    "max_devices": 3,
    "note": "Team A",
    "portal_url": "{{ panel_base_url }}/sub?u=alice"
  }
}

{
  "success": true,
  "users": [{
    "id": 12,
    "username": "alice",
    "is_active": true,

  }],

}

Edit a user

curl -X PATCH '{{ api_base_url }}/users/12' \
  -H 'X-API-Key: sk-your-key' -H 'Content-Type: application/json' \
  -d '{"duration_days":60,"max_traffic_gb":200,"note":"Renewed"}'

Change password

curl -X POST '{{ api_base_url }}/users/12/password' \
  -H 'X-API-Key: sk-your-key' -H 'Content-Type: application/json' \
  -d '{"password":"new-password"}'

Enable or disable a user

curl -X POST '{{ api_base_url }}/users/12/status' \
  -H 'X-API-Key: sk-your-key' -H 'Content-Type: application/json' \
  -d '{"is_active":false}'

Delete a user

curl -X DELETE '{{ api_base_url }}/users/12' \
  -H 'X-API-Key: sk-your-key'

Fields

  • duration_days: 0 means lifetime; on edit it sets lifetime.
  • max_traffic_gb: 0 means unlimited.
  • max_devices is limited to 1–10.
  • Passwords are returned only after create or password change; they are never included in list/get responses.

Responses

Successful responses contain success: true. Errors contain success: false and an error message. Common status codes are 201 (created), 400 (invalid input), 401 (invalid key), 404 (not found), and 409 (duplicate username).

{
  "success": false,
  "error": "A valid API key is required."
}
