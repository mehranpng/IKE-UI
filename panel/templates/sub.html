Connection Setup Tutorials

Native IKEv2 / IPsec setup instructions for all devices with your active credentials

  • 1
    Go to Settings > General > VPN & Device Management > VPN.
  • 2
    Tap Add VPN Configuration... and select Type: IKEv2.
  • 3
    Fill in configuration parameters:
    • Server: {{ server_domain }}
    • Remote ID: {{ server_domain }}
    • Local ID: (Leave Empty)
    • User Authentication: Username
    • Username: {{ user.username }}
    • Password: {{ user.password }}
  • 4
    Tap Done and toggle the VPN switch to connect.
  • 1
    Open Settings > Network & internet > VPN (or search for VPN in Settings).
  • 2
    Tap + (Add VPN Profile) and choose Type: IKEv2/IPsec MSCHAPv2.
  • 3
    Fill in credentials:
    • Name: IKEv2 VPN
    • Server address: {{ server_domain }}
    • IPsec identifier: {{ server_domain }}
    • Username: {{ user.username }}
    • Password: {{ user.password }}
  • 4
    Save the profile and tap to connect.
  • 1
    If connecting through home/NAT routers, run once in Command Prompt (Admin) and restart Windows:
    reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\PolicyAgent" /v "AssumeUDPEncapsulationContextOnSendRule" /t REG_DWORD /d 2 /f
  • 2
    Go to Settings > Network & internet > VPN > Add VPN.
  • 3
    Set fields as follows:
    • VPN Provider: Windows (built-in)
    • Connection Name: IKEv2 VPN
    • Server name or address: {{ server_domain }}
    • VPN Type: IKEv2
    • Type of sign-in info: User name and password
    • User name: {{ user.username }}
    • Password: {{ user.password }}
  • 4
    Click Save and then click Connect.
  • 1
    Install NetworkManager StrongSwan plugin:
    sudo apt update && sudo apt install -y network-manager-strongswan libcharon-extra-plugins libcharon-extauth-plugins
  • 2
    Create connection profile with your credentials:
    nmcli connection add type vpn vpn-type strongswan con-name "IKEv2-VPN" vpn.data "address={{ server_domain }}, method=eap, user={{ user.username }}, certificate=/etc/ssl/certs/ISRG_Root_X1.pem, virtual=yes" vpn.secrets "password={{ user.password }}"
  • 3
    Start the VPN connection:
    nmcli connection up "IKEv2-VPN"
